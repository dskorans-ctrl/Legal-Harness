# CARD 06-A: Brief outline
Tier: STRONG (stronger model, or attorney writes from this card) | Output: Markdown | Temperature: 0.2

## Your one job
Build the outline: headings, sub-points, and which authorities and record items each point uses.

## You receive
- Drafting header (document type, court, relief, page limit, the attorney's arguments in order).
- A list of the authorities packet labels with one line each, and the record packet labels.

## Steps
1. One heading per argument. The heading states the conclusion the court should reach, not a topic.
2. Procedural bars (preservation, waiver, standing, timeliness) go first when in play.
3. Under each heading: numbered sub-points; for each, the authority labels and record labels it will use.
4. List every [CITATION NEEDED] gap.

## Format
```
I. [Conclusion heading]
   1. [sub-point]  Authorities: A1, A3  Record: R-A12, CH-0041
   2. [sub-point]  Authorities: [CITATION NEEDED: ...]  Record: ...
```

## Final check
- Headings state conclusions. Only packet labels used.
