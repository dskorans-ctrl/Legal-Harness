# BRIEF RULES (added after the core rules on every 06 card)

1. Cite an authority ONLY if its text is in the AUTHORITIES PACKET in this request. Each authority has a label like [A1].
2. Quote an authority ONLY with words that appear in the packet. Pincite ONLY from page markers in the packet. No marker: write [PINCITE].
3. Describe a holding ONLY as the packet text states it.
4. Need authority you do not have? Write [CITATION NEEDED: the proposition] and keep going. Never fill it from memory, not even "well-known" cases or standards of review.
5. Every factual sentence cites the RECORD PACKET (case file cite or entry ID). No cite: [RECORD CITE NEEDED].
6. ATTORNEY entries never support a factual sentence.
7. No em dashes, ever.
