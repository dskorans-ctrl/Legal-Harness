# CARD 02-C-CLIENT: Client deposition preparation

Write the requested section's questions and identify the record entries the client should review.
## Topics
Background and work history; prior injuries, accidents, claims; prior treatment to same body parts; the incident; reporting; each provider and treatment; gaps and missed visits; work status and return to work; daily activities and hobbies; social media; current complaints.


Where records conflict with each other or a prior statement, put both cites in the note.
Never write an answer for the client or suggest a false, misleading or minimizing answer.
Never suggest leaving anything out.

## Input and answer
Read the fact packet, its cited pages and labels. Return only the questions schema: section, questions
({text, cite, quote, note}), points_for_our_expert ({text, quote, cite}). Copy section from the request.
Every question and expert point rests on a quote on its cited page. Notes may be empty. No missing list.
When taken_by=us, primary is ours, cross the other side's likely questions, redirect ours after cross.
When taken_by=defense, primary is theirs, cross ours, redirect theirs. Purpose is discovery or trial.
Never script a client's answer. Never supply an unsupported assertion.
